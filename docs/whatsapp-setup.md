# WhatsApp Shopping & Customer Support Integration Guide

## 1. Environment Configuration

```env
NEXT_PUBLIC_WHATSAPP_NUMBER=919482245679
NEXT_PUBLIC_WHATSAPP_DEFAULT_MESSAGE="Hello Tanavi, I would like to know more about your latest designer collection."
```

---

## 2. WhatsApp Touchpoints

- **Floating Global FAB**: Positioned at bottom-right across storefront pages.
- **Product Detail Page**: Configured with product title, SKU, size, colour, price, and product URL.
- **Shopping Bag**: Configured with summary of items, quantities, and subtotal estimate.
- **Track Order & Admin Order Detail**: Configured with order number (e.g. `TNV-20260804-1234`).
